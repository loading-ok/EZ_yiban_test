# EZ_yiban_test
> 专为**自我检测、课后复习、知识巩固**而设计的学习辅助工具。它能帮你快速从题库和手册中检索答案，把节省下来的时间用在真正的理解与思考上。

---

## 🌟 功能亮点

- **多格式题库导入**：支持 `txt`、`doc`、`docx`、`pdf`、`xls`、`xlsx` 等常见格式，轻松整理你的学习资料。
- **手册智能检索**：导入手册（同样支持多种格式），自动匹配题目相关段落，帮你追根溯源。
- **网页题目实时抓取**：通过浏览器调试模式，自动识别网页中的题目并给出题库答案与手册参考。
- **手动粘贴即时匹配**：复制题目粘贴到窗口，0.35 秒内自动匹配，方便快捷。
- **抓取记录独立导出**：即使没有题库或手册，也能单独抓取网页内容并导出为 `txt`，方便整理笔记。
- **完全离线处理**：题库、手册、匹配逻辑均在本地运行，不上传任何数据，隐私安全。

## 🖥️ 使用教程

### 1. 环境准备（仅首次需要）

- 安装 **Python 3.10+**（安装时务必勾选 “Add Python to PATH”）。
- 打开命令行，安装依赖：
  
  pip install python-docx pdfplumber PyPDF2 openpyxl xlrd pandas selenium pywin32

  （win+r打开一个窗口，输入cmd，然后直接复制上面这一段，回车运行）
- 如果不需要网页抓取，可以跳过 `selenium`。

### 2. 启动程序

这个要教吗？
双击运行程序哦
运行成功了？宝宝真蚌！

### 3. 导入题库 / 手册

- 点击 **“导入题库”**，选择你的题库文件，程序会自动解析并显示题目数量。
- 点击 **“导入手册”**，选择手册文件，程序会切分句子并建立检索索引。
- 题库和手册**可以只导入一个，也可以两个都导入**。（也可以不导入，直接使用网页抓取然后导出，用以获取题目）

### 4. 网页抓取（可选）

- **以调试模式启动浏览器**（Chrome 或 Edge）：

  chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\chrome_debug"

  或

  msedge.exe --remote-debugging-port=9222 --user-data-dir="C:\edge_debug"

- 用这个浏览器打开题目页面。（注：该抓取默认抓调试窗口的第一个页面。记得将题目窗口顺序调到第一位，或者直接关闭前置网页，然后按开始）
- 在程序中点击 **“连接浏览器”**，成功后点击 **“开始”**，程序会自动抓取并匹配。
- 点击 **“结束”** 停止抓取。
- 抓取错误，检查是否满足第一条页面顺序问题。如果是，改好窗口，关掉程序重启，或*结束**清空记录*后重新开始试试

### 5. 手动粘贴匹配

- 在 **“手动粘贴区”** 粘贴题目（支持右键菜单和 Ctrl+V）。
- 程序会自动匹配题库并显示答案，同时从手册中搜索相关句子。

### 6. 导出抓取记录

- 点击 **“导出题目”**，选择保存位置，即可将抓取到的所有内容导出为 `txt` 文件。
- 点击 **“清空记录”** 可以重新开始累积。

## ❓ 常见问题

**Q：导入 PDF 时提示缺少 pdfplumber？**
A：请执行 `pip install pdfplumber`。如果仍失败，可尝试 `pip install PyPDF2`，或者将 PDF 另存为 `txt` 再导入。

**Q：连接浏览器失败怎么办？**
A：请确认浏览器已**完全关闭**，然后用调试模式命令重新启动。端口号默认为 `9222`，如果被占用可以换成 `9223` 等。

**Q：抓取不到题目？**
A：可能是题干太短（少于 6 个字），可以在代码中调整 `MIN_STEM_LEN`。也可能是页面结构特殊，建议使用“手动粘贴”功能。
